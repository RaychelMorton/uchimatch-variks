Решите уравнение методом разложения на множители: x³ - 5x² - 4x + 20 = 0. В ответ запишите сумму всех его действительных корней.
Правильный ответ:
5
Подробное развернутое решение:
Сгруппируем слагаемые: (x³ - 5x²) - (4x - 20) = 0. Вынесем общие множители: x²(x - 5) - 4(x - 5) = 0. Теперь вынесем общую скобку (x - 5): (x - 5)(x² - 4) = 0. Отсюда либо x - 5 = 0 (x = 5), либо x² - 4 = 0 (x = 2 или x = -2). Корни уравнения: 5, 2, -2. Их сумма равна: 5 + 2 + (-2) = 5.
